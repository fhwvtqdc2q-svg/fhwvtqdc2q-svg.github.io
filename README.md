# Legal Documents Hub

This repository serves as a central, reusable location for legal and policy templates that can be adapted across the applications and services maintained by `fhwvtqdc2q-svg`.

## Purpose

These documents are designed to help standardize legal language across multiple projects, including:

- web applications
- desktop applications
- API-based tools
- experimental software projects

## Included documents

- `TERMS_OF_USE.md` — bilingual terms of use template
- `PRIVACY_POLICY.md` — bilingual privacy policy template
- `DISCLAIMER.md` — bilingual disclaimer template
- `LOCALIZATION_POLICY.md` — bilingual localization and Arabic language support policy

## How to reuse

1. Copy the relevant file into the target repository.
2. Replace all placeholders such as:
   - `[APP_NAME]`
   - `[OPERATOR_NAME]`
   - `[CONTACT_EMAIL]`
   - `[EFFECTIVE_DATE]`
   - `[JURISDICTION]`
3. Adjust sections related to data collection, payments, integrations, analytics, cookies, and user accounts to match the actual behavior of the application.
4. Publish the final version in the application, website, or repository.

## Important notice

These templates are provided for operational convenience only.
They are **not legal advice** and may not be sufficient for your jurisdiction, industry, or compliance obligations.
You should have the final versions reviewed by a qualified lawyer before using them in production.

# مركز المستندات القانونية

يُستخدم هذا المستودع كمركز موحّد وقابل لإعادة الاستخدام لملفات الشروط والسياسات القانونية التي يمكن تكييفها عبر التطبيقات والخدمات التابعة للحساب `fhwvtqdc2q-svg`.

## الهدف

تم إعداد هذه المستندات للمساعدة في توحيد الصياغة القانونية عبر عدة مشاريع، مثل:

- تطبيقات الويب
- تطبيقات سطح المكتب
- الأدوات المعتمدة على API
- المشاريع البرمجية التجريبية

## الملفات المتوفرة

- `TERMS_OF_USE.md` — قالب شروط الاستخدام بالعربية والإنجليزية
- `PRIVACY_POLICY.md` — قالب سياسة الخصوصية بالعربية والإنجليزية
- `DISCLAIMER.md` — قالب إخلاء المسؤولية بالعربية والإنجليزية
- `LOCALIZATION_POLICY.md` — قالب سياسة الترجمة ودعم اللغة العربية

## طريقة الاستخدام

1. انسخ الملف المناسب إلى المستودع المستهدف.
2. استبدل جميع العناصر المتغيرة مثل:
   - `[APP_NAME]`
   - `[OPERATOR_NAME]`
   - `[CONTACT_EMAIL]`
   - `[EFFECTIVE_DATE]`
   - `[JURISDICTION]`
3. عدّل الأقسام المتعلقة بجمع البيانات، والمدفوعات، والتكاملات، والتحليلات، وملفات الارتباط، وحسابات المستخدمين بما يتوافق مع التطبيق الفعلي.
4. انشر النسخة النهائية داخل التطبيق أو الموقع أو المستودع.

هذه القوالب مقدمة لتسهيل العمل التنظيمي فقط.
هي **ليست استشارة قانونية**، وقد لا تكون كافية حسب الدولة أو القطاع أو متطلبات الامتثال الخاصة بك.
يُنصح بمراجعة النسخة النهائية من قبل محامٍ مختص قبل استخدامها في بيئة إنتاجية.
